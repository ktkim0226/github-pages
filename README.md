# GitHub Pages 배포용 설비 바코드·QR 스캐너

## 배포

1. 새 GitHub 저장소를 만듭니다.
2. 이 압축파일 안의 모든 파일을 저장소 최상위에 올립니다.
3. `Settings > Pages`로 이동합니다.
4. Source를 `Deploy from a branch`로 선택합니다.
5. `main` 브랜치와 `/(root)`를 선택하고 저장합니다.
6. 생성된 `https://사용자명.github.io/저장소명/` 주소로 접속합니다.

## 모바일 권장 환경

- iPhone: 최신 iOS Safari
- Android: 최신 Chrome
- 반드시 GitHub Pages의 HTTPS 주소로 접속
- 카메라 권한 허용
- iPhone은 Safari 공유 메뉴에서 `홈 화면에 추가` 가능

## 사용 흐름

1. 링명과 국사명 입력
2. Rack/Shelf 생략 여부 선택
3. 작업 시작
4. 필요한 단계부터 순차 스캔
5. 코드가 한 번 인식되면 즉시 카메라 정지 후 확인창 표시
6. 실제 라벨 문자와 비교 후 반영
7. Slot 상세정보 입력 후 저장
8. 다음 Slot 연속 스캔
9. CSV 내보내기 또는 JSON 백업

## 다중 사용자

GitHub Pages는 정적 사이트이므로 모든 사용자가 같은 URL을 이용할 수 있습니다.
각 사용자의 데이터는 해당 모바일 브라우저의 localStorage에 저장되어 서로 섞이지 않습니다.
브라우저 데이터 삭제, 시크릿 모드, 기기 교체 시 데이터가 사라질 수 있으므로 CSV 또는 JSON 백업을 권장합니다.

## 정확도

카메라 기반 인식은 100% 정확도를 기술적으로 보장할 수 없습니다.
본 프로그램은 사용자가 같은 코드를 반복 스캔하지 않도록 하면서 아래 방식으로 오인식 자동 반영을 줄입니다.

- 후면 카메라 우선
- 화면 중앙 단일 코드 가이드
- 한 번 인식되면 즉시 카메라 정지
- 카메라 자동 정지
- 사용자 최종 육안 확인
- 사용자 확인 전 자동 저장 금지

실제 현장 라벨로 iPhone과 Android 각각 사전 검증해야 합니다.

## v4 변경사항

- 카메라 목록을 먼저 조회하고 후면 카메라 ID로 실행
- 카메라 ID 실행 실패 시 `facingMode: environment`로 자동 재시도
- CDN 라이브러리를 HTML에서 먼저 로드하고 보조 CDN 제공
- 스캔 및 수동 입력 후 확인창 제거, 즉시 현재 단계에 반영
- 수동 입력은 영문 대문자와 숫자만 허용
- Slot Number는 `[0-9A-F][0-9][0-9]` 형식 허용
- 모바일 화면 여백과 버튼 크기 개선

## v5 스캐너 개선

- 카메라를 페이지 내부가 아닌 전체 화면 팝업으로 실행
- 팝업 실행 중 배경 페이지 스크롤 차단
- 상단 닫기 및 하단 스캔 중지 버튼
- 자동 / 1D 바코드 / QR 전용 모드
- 자동 모드는 지원 형식을 제한하지 않고 전체 형식 검사
- 기기 지원 시 네이티브 BarcodeDetector 사용
- 1920×1080 이상 후면 카메라 해상도 요청
- 연속 초점 요청
- 기기 지원 시 조명 및 줌 컨트롤
- 화면 영역별 색상 구분

## v6 변경사항

- 5mm 내외 코드를 위한 소형 코드 모드
- 최대 4K 후면 카메라 해상도 요청
- 소형 코드 모드에서 지원 기기의 광학/디지털 줌 자동 적용
- 고해상도 사진 촬영 후 정지사진 디코딩
- Rack/Shelf/Slot 요약값을 선택해 재스캔 또는 재수동 입력
- 입력 중인 작업정보 전체 초기화 버튼
- 출력은 CSV 내보내기만 유지
- JSON 백업/복원, 전체 데이터 삭제, 자체 테스트 버튼 제거


## GitHub Pages 배포(v8)

1. ZIP 압축을 풉니다.
2. ZIP 안의 파일과 폴더를 저장소 루트에 업로드합니다. `index.html`이 저장소 루트에 있어야 합니다.
3. GitHub 저장소의 **Settings → Pages**에서 `Deploy from a branch`, `main`, `/ (root)`를 선택합니다.
4. 배포된 `https://계정명.github.io/저장소명/?v=8` 주소를 모바일 Safari 또는 Chrome에서 엽니다.
5. 카메라 권한을 허용합니다.

GitHub Pages는 HTTPS이므로 `getUserMedia()` 카메라 API를 사용할 수 있습니다. ZXing JavaScript는 jsDelivr에서 불러오고, 실패하면 unpkg로 한 번 더 시도합니다. WASM 디코더는 고정 버전 `3.1.2`를 사용합니다. 따라서 최초 실행 및 새 기기에서 인터넷 연결이 필요합니다.

### 주의

- GitHub Pages 주소가 아닌 로컬 `file://` 방식으로 `index.html`을 직접 열면 카메라가 정상 동작하지 않을 수 있습니다.
- 회사 보안망에서 jsDelivr와 unpkg가 모두 차단되면 스캐너 엔진을 불러오지 못합니다.
- 5mm Micro QR/바코드는 지원 형식이라도 카메라 최소 초점 거리와 인쇄 품질에 따라 인식되지 않을 수 있습니다. 이때는 `Micro/소형` 모드와 `고해상도 사진으로 인식`을 사용합니다.
