# GitHub Pages 배포용 설비 바코드·QR 스캐너

## 배포

1. 새 GitHub 저장소를 만듭니다.
2. 이 압축파일 안의 모든 파일을 저장소 최상위에 올립니다.
3. `Settings > Pages`로 이동합니다.
4. Source를 `Deploy from a branch`로 선택합니다.
5. `main` 브랜치와 `/(root)`를 선택하고 저장합니다.
6. 생성된 `https://사용자명.github.io/저장소명/` 주소로 접속합니다.

## 모바일 권장 환경

- iPhone: 최신 iOS Safari
- Android: 최신 Chrome
- 반드시 GitHub Pages의 HTTPS 주소로 접속
- 카메라 권한 허용
- iPhone은 Safari 공유 메뉴에서 `홈 화면에 추가` 가능

## 사용 흐름

1. 링명과 국사명 입력
2. Rack/Shelf 생략 여부 선택
3. 작업 시작
4. 필요한 단계부터 순차 스캔
5. 코드가 한 번 인식되면 즉시 카메라 정지 후 확인창 표시
6. 실제 라벨 문자와 비교 후 반영
7. Slot 상세정보 입력 후 저장
8. 다음 Slot 연속 스캔
9. CSV 내보내기 또는 JSON 백업

## 다중 사용자

GitHub Pages는 정적 사이트이므로 모든 사용자가 같은 URL을 이용할 수 있습니다.
각 사용자의 데이터는 해당 모바일 브라우저의 localStorage에 저장되어 서로 섞이지 않습니다.
브라우저 데이터 삭제, 시크릿 모드, 기기 교체 시 데이터가 사라질 수 있으므로 CSV 또는 JSON 백업을 권장합니다.

## 정확도

카메라 기반 인식은 100% 정확도를 기술적으로 보장할 수 없습니다.
본 프로그램은 사용자가 같은 코드를 반복 스캔하지 않도록 하면서 아래 방식으로 오인식 자동 반영을 줄입니다.

- 후면 카메라 우선
- 화면 중앙 단일 코드 가이드
- 한 번 인식되면 즉시 카메라 정지
- 카메라 자동 정지
- 사용자 최종 육안 확인
- 사용자 확인 전 자동 저장 금지

실제 현장 라벨로 iPhone과 Android 각각 사전 검증해야 합니다.
