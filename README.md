# 자산바코드 스캐너 v1.0.16

초기 실행 시 `신규 증설` 또는 `재배치`를 선택합니다.

- 신규 증설: 기존 Rack/Shelf/Slot 순차 스캔 기능을 유지합니다.
- 재배치: 재배치 전(국사, 링명, 슬롯, 파장), 유니트명, 유니트바코드, 재배치 후(국사, 링명, 슬롯, 파장)를 입력합니다.
- 재배치의 모든 항목은 선택 입력이며 유니트바코드만 카메라로 스캔할 수 있습니다.
- 두 작업 유형의 데이터는 하나의 저장 목록에 보관하며 작업 유형별 XLSX 파일로 내보냅니다.

GitHub Pages 저장소 루트에 모든 파일을 업로드한 뒤 접속하세요.

- 새 버전 감지 배너

- 입력 초기화는 이미 저장된 목록과 XLSX 파일을 삭제하지 않습니다.
- 새 서비스 워커 활성화 후 페이지 1회 자동 새로고침


## v1.0.16 주요 기능
- 카메라 화면에 `카메라 조명`과 `자동 초점`을 녹색 ON/OFF 스위치 형태로 표시합니다.
- 자동 초점 OFF 시 앱의 연속 초점 유지, 중앙 재초점 및 Android 흐림 감지 재초점을 중단합니다.
- 카메라가 manual/fixed 초점 모드를 지원하면 자동 초점 OFF를 카메라 트랙에도 적용합니다.
- 프레임 밝기가 기준값보다 낮을 때만 `촬영 TIP`과 `조명이 너무 어둡습니다. 카메라 조명을 켜주세요.` 문구를 표시합니다.
- 밝기가 정상 범위로 회복되면 촬영 팁을 즉시 숨깁니다.
- 카메라 실행 시 연속 자동초점을 기본으로 활성화하고 `자동 초점 ON` 상태를 표시합니다.
- 자동 초점 버튼을 누르면 화면 중앙을 기준으로 단일 재초점 후 연속 자동초점으로 복귀합니다.
- Android에서는 기존 흐림 감지 자동 재초점 모니터를 계속 사용합니다.
- 조명 지원 기기에서만 `조명 켜기/끄기` 버튼을 표시하고 실제 적용 상태와 버튼 색상을 동기화합니다.
- 일반 작업 화면 UI/UX는 v1.0.12 구성을 그대로 유지합니다.
- 카메라 스캔 전체화면만 헤더, 모드 탭, 인식 프레임, 상태 칩, 초점·조명·종료 버튼, 고급 설정 패널을 새 디자인으로 개선했습니다.
- 자동·1D·QR·소형 모드의 실제 스캔 프레임 비율은 v1.0.12와 동일합니다.
- 카메라 선택·자동초점·ROI 계산·ZXing/BarcodeDetector 판독·후보 확정 로직은 v1.0.12와 동일합니다.
- 재배치 전/후 파스텔 빨강·파랑 구역 구분
- 신규 증설/재배치 저장 목록 및 XLSX 분리
- Android·iPhone 카카오톡 공유는 XLSX 파일과 저장된 행 내용을 한 공유 데이터에 함께 전달합니다.
- 파일과 내용의 결합 공유가 제한된 환경에서는 내용 공유를 우선하고 XLSX 파일을 단말에 저장합니다.
- 시스템 공유까지 제한된 브라우저에서는 전체 내용을 클립보드에 복사하고 XLSX 파일을 저장합니다.
- BarcodeDetector + ZXing-C++ 병렬 고속 판독, 실패 시 2영역 병렬 정밀 판독

## v1.0.16 XLSX 파일명 및 양식

- 신규 증설: `신규증설_자산바코드_YYYYMMDD-N.xlsx`
- 재배치: `재배치_자산바코드_YYYYMMDD-N.xlsx`
- 신규 증설 파일은 `링명, 설치국사, 인프라, 공사번호, 국사바코드, TID, 랙 바코드, 셀프 바코드, 실장슬롯, 파장, 실장 품목, 부속바코드번호, 구축일시, 작업자, 비고` 순서로 저장합니다.
- 신규 증설의 인프라·공사번호·국사바코드·TID·작업자는 열을 유지하고 공란으로 저장합니다.
- 재배치 파일은 `재배치 전 사용 내역`, `LG CNS 실적 자산인계 내역`, `LG U+ 원 요청내역`, `재배치 후 사용 내역`의 병합 그룹 헤더를 사용합니다.
- 재배치 전·후의 인프라 및 두 인계지역→인수지역 열은 열을 유지하고 공란으로 저장합니다.
- 신규 증설 부속바코드와 재배치 LG CNS 바코드 열은 노란색으로 표시합니다.
- 날짜는 단말 현지 날짜를 사용합니다.
- 같은 날짜에 동일 작업유형을 반복 내보내면 N이 1부터 증가합니다.
- 신규 증설과 재배치의 순번은 별도로 관리됩니다.

## v1.0.16 스캔 성능 개선
- 제공된 실물 샘플에서 확인된 QR·Code128·Code93을 첫 고속 판독 경로에 배치했습니다.
- 자동 모드는 가로 1D 입력과 스캔 영역 전체를 90도 회전한 세로 1D 입력을 동시에 판독합니다.
- 바코드 전용 모드도 가로·세로 입력을 병렬 판독하므로 세로로 부착된 좁은 라벨을 따로 돌릴 필요가 없습니다.
- ZXing이 체크섬을 포함해 유효하다고 판정한 결과만 후보값으로 사용합니다.
- 자동 모드에서 1D 바코드용 가로 ROI와 QR/DataMatrix용 정사각 ROI를 병렬 판독합니다.
- 모든 프레임에서 네이티브 판독과 ZXing 고속 판독을 먼저 병렬 실행하고, 실패한 경우에만 2영역 정밀 판독을 추가합니다.
- 균형 프로필의 첫 판독 주기와 정밀 보강 진입 시간을 단축했습니다.
- 같은 영상 프레임의 중복 결과는 1회로 계산하고, 서로 다른 프레임 2회 일치 또는 네이티브·ZXing 교차 일치 시에만 확정합니다.
- 스캔 모드별 네이티브 판독기와 자동 모드의 1D·2D 캔버스를 재사용하여 반복 생성 부하를 줄였습니다.
- 자동 및 소형 모드의 정밀 판독 포맷을 명시하여 QR·DataMatrix·주요 1D 바코드의 누락을 줄였습니다.
- 카메라를 1080p/30fps 중심으로 요청하여 4K 프레임 처리 부하를 줄였습니다.
- 지원 기기에서는 연속 초점, 연속 노출, 자동 화이트밸런스를 함께 요청합니다.
- 카메라 시작·전환·스캔 모드 변경 때 연속 자동초점을 자동 적용하고, 스캔 중 2초마다 활성 상태를 확인합니다.
- 웹 초점 제어를 지원하지 않는 기기에서는 카메라의 기본 자동초점을 그대로 유지합니다.
- Android 자동 선택에서는 특정 렌즈를 `deviceId`로 강제하지 않고 후면 기본 카메라를 요청하여 갤럭시 다중 카메라의 초광각·접사 렌즈 오선택을 줄였습니다.
- 초점·노출·화이트밸런스 제어를 개별 적용하여 한 항목의 미지원으로 자동초점 설정 전체가 취소되지 않도록 했습니다.
- Android에서는 카메라 시작 직후 단일 초점 펄스와 연속 초점 복귀를 자동 실행합니다.
- 수동 초점 버튼은 지원 기기에서 `single-shot` 후 `continuous`로 복귀하여 실제 재초점을 유도합니다.
- Android 다중 카메라에서는 최초 실행 시 각 렌즈의 후면 여부와 `continuous`·`single-shot`·초점거리·조명·줌 지원을 점검합니다.
- 자동초점 기능 점수가 가장 높은 후면 렌즈를 기본 카메라로 선택하고, Rack/Shelf/Slot 단계 재시작 시 같은 렌즈를 재사용합니다.
- 초광각·접사·망원·심도 렌즈로 표시된 카메라는 기본 렌즈 자동 선택 우선순위를 낮춥니다.
- Android 후면 렌즈 자동 점검 시 중앙 영상의 밝기와 경계 선명도를 실제로 측정하여 바코드 거리에서 가장 또렷한 렌즈를 우선합니다.
- 지원 브라우저에서는 중앙 `pointsOfInterest`를 지정해 초점·노출·화이트밸런스의 3A 기준점을 코드 영역으로 유도합니다.
- 스캔 중 적정 밝기인데 선명도가 연속으로 낮으면 자동 재초점 펄스를 실행하고, 선명도가 회복되면 즉시 중단합니다.
- 자동 재초점은 스캔 1회당 최대 6회로 제한하여 지속적인 초점 헌팅을 방지합니다.
- 화면의 실제 스캔 프레임 위치를 `object-fit: cover` 영상 좌표로 역산해 모든 실시간 판독 입력을 프레임 내부로 제한합니다.
- 네이티브 BarcodeDetector도 전체 영상을 직접 읽지 않고 스캔 영역을 잘라낸 캔버스만 판독합니다.
- Android에서는 스캔 영역을 최대 1600px 이상으로 유지하고 작은 코드를 위한 고해상도 확대 입력을 사용합니다.
- 자동 모드는 영역 내부 전체·1D 가로·2D 정사각 입력을 병렬 판독하며, 반전·노이즈 제거·정밀 탐색을 고속 경로에도 적용합니다.
- 정밀 판독의 모든 하위 영역도 스캔 프레임 내부에서만 생성됩니다.
