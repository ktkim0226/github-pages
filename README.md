# 자산바코드 스캐너 v1.0.7

초기 실행 시 `신규 증설` 또는 `재배치`를 선택합니다.

- 신규 증설: 기존 Rack/Shelf/Slot 순차 스캔 기능을 유지합니다.
- 재배치: 재배치 전(국사, 링명, 슬롯, 파장), 유니트명, 유니트바코드, 재배치 후(국사, 링명, 슬롯, 파장)를 입력합니다.
- 재배치의 모든 항목은 선택 입력이며 유니트바코드만 카메라로 스캔할 수 있습니다.
- 두 작업 유형의 데이터는 하나의 저장 목록에 보관하며 작업 유형별 XLSX 파일로 내보냅니다.

GitHub Pages 저장소 루트에 모든 파일을 업로드한 뒤 접속하세요.

## v1.0.7 XLSX 파일명 및 양식

- 신규 증설: `신규증설_자산바코드_YYYYMMDD-N.xlsx`
- 재배치: `재배치_자산바코드_YYYYMMDD-N.xlsx`
- 신규 증설 파일은 `링명, 설치국사, 인프라, 공사번호, 국사바코드, TID, 랙 바코드, 셀프 바코드, 실장슬롯, 파장, 실장 품목, 부속바코드번호, 구축일시, 작업자, 비고` 순서로 저장합니다.
- 신규 증설의 인프라·공사번호·국사바코드·TID·작업자는 열을 유지하고 공란으로 저장합니다.
- 재배치 파일은 `재배치 전 사용 내역`, `LG CNS 실적 자산인계 내역`, `LG U+ 원 요청내역`, `재배치 후 사용 내역`의 병합 그룹 헤더를 사용합니다.
- 재배치 전·후의 인프라 및 두 인계지역→인수지역 열은 열을 유지하고 공란으로 저장합니다.
- 신규 증설 부속바코드와 재배치 LG CNS 바코드 열은 노란색으로 표시합니다.
- 날짜는 단말 현지 날짜를 사용합니다.
- 같은 날짜에 동일 작업유형을 반복 내보내면 N이 1부터 증가합니다.
- 신규 증설과 재배치의 순번은 별도로 관리됩니다.

## v1.0.7 스캔 성능 개선
- 자동 모드에서 1D 바코드용 가로 ROI와 QR/DataMatrix용 정사각 ROI를 병렬 판독합니다.
- 모든 프레임에서 네이티브 판독과 ZXing 고속 판독을 먼저 병렬 실행하고, 실패한 경우에만 2영역 정밀 판독을 추가합니다.
- 균형 프로필의 첫 판독 주기와 정밀 보강 진입 시간을 단축했습니다.
- 같은 영상 프레임의 중복 결과는 1회로 계산하고, 서로 다른 프레임 2회 일치 또는 네이티브·ZXing 교차 일치 시에만 확정합니다.
- 스캔 모드별 네이티브 판독기와 자동 모드의 1D·2D 캔버스를 재사용하여 반복 생성 부하를 줄였습니다.
- 자동 및 소형 모드의 정밀 판독 포맷을 명시하여 QR·DataMatrix·주요 1D 바코드의 누락을 줄였습니다.
- 카메라를 1080p/30fps 중심으로 요청하여 4K 프레임 처리 부하를 줄였습니다.
- 지원 기기에서는 연속 초점, 연속 노출, 자동 화이트밸런스를 함께 요청합니다.
- 카메라 시작·전환·스캔 모드 변경 때 연속 자동초점을 자동 적용하고, 스캔 중 2초마다 활성 상태를 확인합니다.
- 웹 초점 제어를 지원하지 않는 기기에서는 카메라의 기본 자동초점을 그대로 유지합니다.
- Android 자동 선택에서는 특정 렌즈를 `deviceId`로 강제하지 않고 후면 기본 카메라를 요청하여 갤럭시 다중 카메라의 초광각·접사 렌즈 오선택을 줄였습니다.
- 초점·노출·화이트밸런스 제어를 개별 적용하여 한 항목의 미지원으로 자동초점 설정 전체가 취소되지 않도록 했습니다.
- Android에서는 카메라 시작 직후 단일 초점 펄스와 연속 초점 복귀를 자동 실행합니다.
- 수동 초점 버튼은 지원 기기에서 `single-shot` 후 `continuous`로 복귀하여 실제 재초점을 유도합니다.
