# Rack·Shelf·Slot Scanner v12

GitHub Pages용 정적 웹앱입니다. v12은 단말별 카메라 차이와 순간 오인식을 줄이기 위해 카메라 선택, 초점 재요청, 빠른 줌, 영상 품질 안내, 다중 프레임 합의 판독을 추가했습니다.

## 핵심 변경
- 동일 값 2회 반복 인식 후 확정(1.8초 투표 창)
- 후면 카메라 자동 선택 + 카메라 수동 선택
- 연속/단발 초점 지원 감지 및 다시 맞춤
- 1×/2×/3× 빠른 줌, 손전등
- 밝기·반사·선명도 실시간 안내
- 자동/1D/QR/Micro 전용 분석 영역
- ZXing-C++ WASM + BarcodeDetector 보조 엔진
- GitHub Pages 캐시 v12 분리

## 배포
ZIP의 모든 파일을 저장소 루트에 업로드하고 GitHub Pages를 main / root로 배포합니다. 배포 후 `?v=11`을 붙여 접속하고 기존 사이트 데이터가 남아 있으면 삭제합니다.

## 제한
브라우저의 수동 초점 위치 제어는 단말별 지원 편차가 큽니다. 지원하지 않는 기기에서는 카메라 재선택·줌·고정 안내로 보완합니다.

## V12 속도/정확도 최적화

- 기본값은 `균형` 프로필입니다.
- 먼저 중앙 원본 프레임에서 Code128, Code39, QR, DataMatrix를 빠르게 검색합니다.
- 균형 프로필에서는 약 650ms 동안 찾지 못하면 전체 영역과 전처리 이미지를 사용하는 정밀 단계로 자동 전환합니다.
- Android Chrome 등 BarcodeDetector 지원 환경에서는 네이티브 엔진을 먼저 실행합니다.
- 평균 판독 시간이 카메라 화면에 표시됩니다.
- 일반 라벨은 `고속` 또는 `균형`, 매우 작거나 손상된 라벨은 `정밀` 또는 `Micro/소형`을 권장합니다.
