# Rack / Shelf / Slot Scanner V13

V12의 고속·정밀 2단계 인식 엔진을 유지하면서 모바일 카메라 미리보기 영역을 확대한 버전입니다.

## 화면 변경
- 헤더와 스캔 모드 버튼 높이 축소
- 카메라 화면이 남은 공간을 최우선 사용
- 판독·품질 상태를 카메라 화면 위 반투명 배지로 표시
- 기본 하단 메뉴는 초점, 조명, 빠른 줌, 종료만 표시
- 카메라 선택, 성능 프로필, 세부 줌, 사진 인식은 고급 설정으로 접음
