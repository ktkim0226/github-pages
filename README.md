# 설비 작업 스캐너 V16

초기 실행 시 `신규 증설` 또는 `재배치`를 선택합니다.

- 신규 증설: V13의 Rack/Shelf/Slot 순차 스캔 기능을 유지합니다.
- 재배치: 재배치 전(국사, 링명, 슬롯, 파장), 유니트명, 유니트바코드, 재배치 후(국사, 링명, 슬롯, 파장)를 입력합니다.
- 재배치의 모든 항목은 선택 입력이며 유니트바코드만 카메라로 스캔할 수 있습니다.
- 두 작업 유형의 데이터는 하나의 저장 목록과 CSV로 내보냅니다.

GitHub Pages 저장소 루트에 모든 파일을 업로드한 뒤 `?v=14`를 붙여 접속하세요.
